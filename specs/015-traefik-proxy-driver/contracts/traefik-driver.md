# Contract: Traefik driver

## Driver object

```ts
traefikDriver = fileDriver({
  id: 'traefik',
  label: 'Traefik',
  capabilities: { authModes: ['forward', 'oidc'], acmeDns01ViaCloudflare: true },
  defaultConfigPath: '/etc/traefik/dynamic/bellhop.yml',
  statusPage: null,
  usesCertResolver: true,
  usesApiUrl: true,
  configPathNote: "Traefik's file provider must watch this file's directory. The whole file is replaced on every apply, and a file Bellhop didn't generate is refused.",
  render,                                  // -> [{ mode: 'owned', ownedHeader: HEADER, atomic: true }]
  validateCommand: (path, { files, inventory }) => inventory.proxyApiUrl ? checkScript(...) : null,
  validateLabel: 'Traefik API check',
  reloadCommand: null,
})
```

`'traefik'` joins `PROXY_DRIVER_IDS`, and it's registered after
HAProxy and before None, so the dropdown order is Caddy, nginx,
Nginx Proxy Manager, HAProxy, Traefik, No proxy.

## Rendered file: example

This example has these inputs:

- `domain` `example.com` and `certResolver` `cloudflare`, with the outpost
  at `192.0.2.5:9000`.
- Entry *wiki* is ungated, with subdomains `wiki` and `docs`, backend
  `192.0.2.20:8080`.
- Entry *media* is forward-gated with exempt paths `["/health", "/api/*"]`,
  subdomain `media`, backend `192.0.2.21:443`, and `insecureBackendTls`
  set.

```yaml
# Generated by Bellhop sync-proxy. Do not edit: this file is replaced on every apply.
http:
  routers:
    bellhop-route-wiki-example-com:
      rule: Host(`wiki.example.com`) || Host(`docs.example.com`)
      entryPoints:
        - websecure
      service: bellhop-route-wiki-example-com
      middlewares:
        - bellhop-forwarded-port
      tls:
        certResolver: cloudflare
    bellhop-route-media-example-com:
      rule: Host(`media.example.com`)
      entryPoints:
        - websecure
      service: bellhop-route-media-example-com
      middlewares:
        - bellhop-forwarded-port
        - bellhop-authentik
      tls:
        certResolver: cloudflare
    bellhop-outpost-media-example-com:
      rule: (Host(`media.example.com`)) && PathPrefix(`/outpost.goauthentik.io/`)
      entryPoints:
        - websecure
      service: bellhop-authentik-outpost
      middlewares:
        - bellhop-forwarded-port
      tls:
        certResolver: cloudflare
    bellhop-exempt-media-example-com:
      rule: (Host(`media.example.com`)) && (Path(`/health`) || PathPrefix(`/api/`))
      entryPoints:
        - websecure
      service: bellhop-route-media-example-com
      middlewares:
        - bellhop-forwarded-port
      tls:
        certResolver: cloudflare
  services:
    bellhop-route-wiki-example-com:
      loadBalancer:
        servers:
          - url: http://192.0.2.20:8080
    bellhop-route-media-example-com:
      loadBalancer:
        servers:
          - url: https://192.0.2.21:443
        serversTransport: bellhop-insecure-backend-tls
    bellhop-authentik-outpost:
      loadBalancer:
        servers:
          - url: http://192.0.2.5:9000
  middlewares:
    bellhop-forwarded-port:
      headers:
        customRequestHeaders:
          X-Forwarded-Port: "443"
    bellhop-authentik:
      forwardAuth:
        address: http://192.0.2.5:9000/outpost.goauthentik.io/auth/traefik
        trustForwardHeader: true
        authResponseHeaders:
          - X-authentik-username
          - X-authentik-groups
          - X-authentik-email
          - X-authentik-name
          - X-authentik-uid
    bellhop-generation-<12 hex>:
      headers:
        customRequestHeaders:
          X-Bellhop-Generation: <12 hex>
  serversTransports:
    bellhop-insecure-backend-tls:
      insecureSkipVerify: true
```

Rules:

- A route whose only exempt pattern is `/*` (or whose patterns include
  `/*`) has no `bellhop-authentik` on its main router and no exempt router,
  but keeps its outpost router.
- A pattern equal to `/outpost.goauthentik.io` or under
  `/outpost.goauthentik.io/` is skipped. If nothing is left, no exempt
  router is rendered.
- Exempt patterns are deduplicated on kind+path and keep their stored order.
- A value containing a backtick is rendered as a JSON-style double-quoted
  string instead of a backtick one.
- With zero routes the file is the header plus `http.middlewares` holding
  `bellhop-forwarded-port` and the marker.

## Apply script (atomic owned file)

For an `atomic` owned file, `buildFileDriverScript`:

- does the header check, backup and trap exactly as today;
- **writes** with:

  ```sh
  TMP_i="$(mktemp '<dir>/.<base>.XXXXXX')"
  if [ -f '<path>' ]; then cp -p '<path>' "$TMP_i"; else chmod 644 "$TMP_i"; fi
  cat > "$TMP_i" <<'BELLHOP_FILE_i'
  ...
  BELLHOP_FILE_i
  mv -f "$TMP_i" '<path>'
  ```

- **restores** in the trap handler the same way (a temp copy of the backup,
  then `mv -f`). A file that didn't exist before is still removed with
  `rm -f`.

## Validate step (proxyApiUrl set)

Sent as the `if ! <validate>; then` condition, as one subshell. `API` is
the single-quoted `proxyApiUrl` with any trailing `/` stripped. `MARKER` is
the file's marker name. `ROUTERS` are the file's router names in rendered
order.

```sh
(
  bellhop_api='<API>'
  bellhop_tries=0
  while :; do
    bellhop_code="$(curl -s -o /dev/null -w '%{http_code}' --max-time 5 "$bellhop_api/api/http/middlewares/<MARKER>@file")"
    [ "$bellhop_code" = "200" ] && break
    bellhop_tries=$((bellhop_tries + 1))
    if [ "$bellhop_tries" -ge 30 ]; then
      # 000 -> "unreachable", else "HTTP <code>"
      printf 'Traefik did not load %s within 30 seconds (%s at %s)\n' '<path>' "<last result>" "$bellhop_api" >&2
      exit 1
    fi
    sleep 1
  done
  bellhop_failed=0
  # one block per router name:
  bellhop_body="$(curl -s --max-time 5 "$bellhop_api/api/http/routers/<ROUTER>@file")"
  case "$bellhop_body" in
    *'"status":"enabled"'*) ;;
    *) printf 'Traefik router %s is not healthy: %s\n' '<ROUTER>' "$bellhop_body" >&2; bellhop_failed=1 ;;
  esac
  exit "$bellhop_failed"
)
```

On failure `fileDriver` prints `Traefik API check failed; restored previous
configuration` (from `validateLabel`), and the trap restores the file.
`apply()` throws with stderr, so both the specific message above and that
line reach the caller.

## Settings API (`GET/PATCH /api/settings`)

`proxyDrivers[]` entries gain `usesCertResolver: boolean` and
`usesApiUrl: boolean`. `settings` gains `proxyCertResolver` and
`proxyApiUrl`. A PATCH that sets `proxyApiUrl` to anything other than an
`http(s)` URL gets a 400 with the schema message, and `set-config` rejects
it with the same message.
