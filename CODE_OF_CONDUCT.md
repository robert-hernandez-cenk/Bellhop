# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The linked text is the full, authoritative version. This file
summarizes it and describes how this project handles reports.

## Summary

Everyone taking part in this project's issues, pull requests, discussions, and other spaces
is expected to be respectful and considerate.

Expected behavior includes:

- Being kind and patient, especially with newcomers
- Respecting differing viewpoints and experiences
- Giving and gracefully accepting constructive feedback
- Taking responsibility for mistakes and learning from them

Unacceptable behavior includes:

- Harassment, insults, or personal or political attacks
- Sexualized language or imagery, or unwelcome advances
- Publishing someone else's private information without their explicit permission
- Trolling, or any other conduct that would reasonably be considered inappropriate in a
  professional setting

## Reporting

To report a problem, use GitHub's **Report content** option on the issue, pull request, or
comment involved, or use any contact method listed on the maintainer's GitHub profile.

There is no email reporting address. As with [SECURITY.md](SECURITY.md), GitHub is the only
reporting channel, so there is no published inbox to monitor.

Reports are handled as privately as possible.

## Enforcement

The maintainer reviews reports and decides on a response at their discretion, following
the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
A response can range from a private warning to a permanent ban from the project.
